# Quadratic programming

Optimizes a quadratic objective under linear equality constraints and nonnegative variables.

```sh
python -m quadratic_programming.main
```

The built-in example returns `x = (1.7, 2.4, 0, 0.3)` with objective value `-19.95`.

The method is in [`core.py`](core.py); [`main.py`](main.py) contains the example.
